How buying works

  1. Send the request Use the quote button on any system, or the suite button above. No account needed.
  2. Get a formal quotation Scope, seats, term and price — with the payment schedule spelled out before anything is signed.
  3. Approve and we implement 50% on approval, 50% once implementation completes. Data import and staff training included.
  4. Go live with support Annual maintenance retainer covers updates, fixes and a named support contact.

Questions buyers ask

Can the systems run without internet?

Yes. Offline POS, the file tracking system and the attendance system keep working locally and sync when a connection returns. The rest run on-premise on your own server.

Where does our data live?

On your infrastructure. There is no shared multi-tenant database, no third-party analytics and no per-user cloud fee. You own the database and can export it at any time.

What does implementation include?

Installation, configuration, migration of existing spreadsheets or registers, role setup and staff training. The one-off setup fee on each system covers that work.

Do you customise?

Yes. Reports, fields and approval rules can be adapted. Custom work is quoted separately so the standard product price stays predictable.

How is the annual maintenance fee calculated?

30% of the contract value, billed annually from go-live. It covers updates, bug fixes and support; it is separate from the two implementation instalments.
